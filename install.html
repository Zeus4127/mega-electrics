Try the Mega Electrics app

It's the whole website as an Android app: works offline, with tap-to-call and email built in. This is a test build (v2.36) for people reviewing the preview.

Android: install in 1 minute

Download the app (45 MB)

  1. Tap Download the app and wait for it to finish.
  2. Open the download (tap the notification, or open Files → Downloads) and tap MegaElectrics.apk.
  3. If the phone asks, allow Install unknown apps for your browser, then go back.
  4. Tap Install. If Play Protect says the developer isn't recognised, tap More details → Install anyway (it's a test build, not from the Play Store).
  5. Tap Open. The app appears as Mega Electrics.

Had an earlier Mega preview app? If installing fails, uninstall the old one first (test builds use different keys).

iPhone

There's no iPhone app in this preview. Open the website in Safari, tap Share → Add to Home Screen, and it opens like an app.
